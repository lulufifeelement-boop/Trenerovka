# Форма — персональный тренировочный план (2.0.0)

Мобильное приложение для тренировок A/B, таймера отдыха, дневника занятий и контроля веса.

## Что умеет

- две программы тренировок A/B;
- фотографии упражнений (два кадра движения) и встроенные схемы на случай ошибки загрузки;
- таймер отдыха, отметка подходов и восстановление незавершённой тренировки;
- настройка рабочих весов, подходов и повторений;
- история тренировок и веса, графики прогресса;
- экспорт и импорт резервной копии JSON;
- установка на главный экран Android и работа офлайн после первой загрузки.

## Запуск

Откройте опубликованный сайт на телефоне в Chrome. Нажмите «Установить» в приложении или выберите «Установить приложение» в меню Chrome. После первой загрузки приложение сохранит пакет локально и подготовит офлайн-кэш.

GitHub Pages публикует сайт автоматически при каждом push в `main` через GitHub Actions. Workflow проверяет контрольную сумму приложения перед публикацией.

## Данные и конфиденциальность

Записи тренировок и вес хранятся в локальном хранилище браузера на устройстве. Приложение не отправляет их на сервер. Для переноса или защиты истории используйте «Профиль → Экспорт JSON». Резервную копию можно восстановить через импорт.

## Состав

`index.html` загружает автономный HTML-бандл из `payload/part-*.txt`. В бандле встроены CSS, JavaScript и фотографии упражнений, поэтому сторонние скрипты и CDN не нужны. `sw.js` кэширует загрузчик и части бандла для офлайн-запуска.
