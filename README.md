# Мои тренировки — v1.1.0

Персональное фитнес-приложение на русском языке. Текущая версия включает три программы тренировок и 23 встроенные SVG-схемы упражнений.

## Запуск

- Для публикации откройте Settings → Pages и один раз выберите Source: GitHub Actions, затем нажмите Save. После этого workflow в Actions сможет развернуть сайт. В репозитории есть PWA-манифест, иконка и Service Worker.
- На телефоне Android откройте опубликованный сайт в Chrome.
- После первой загрузки откройте приложение ещё раз при подключении к интернету, чтобы браузер закэшировал данные для офлайн-запуска.

## Данные

Результаты хранятся локально в браузере. Экспортируйте резервную копию JSON в приложении перед очисткой данных браузера или сменой устройства.

## Состав

Приложение хранится как автономный HTML-бандл, упакованный gzip и разложенный на 15 текстовых частей в `payload/`. `index.html` собирает его в памяти и запускает; исходный код и 23 встроенные SVG-схемы находятся в этом бандле.

Примечание: репозиторий не содержит серверной базы данных и не отправляет тренировочные записи на сервер.
